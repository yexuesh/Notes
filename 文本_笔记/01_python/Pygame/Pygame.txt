# 检测碰撞
1.sprite1.rect.colliderect(sprite2.rect)
如果两个对象的矩形重叠，返回 True，否则返回 False。
2.pygame.sprite.spritecollideany()函数
参数:
第一个必须是 Sprite
第二个必须是 Sprite 组
3.pygame.sprite.spritecollide(sprite, group, dokill, collided = None)  #  精灵与组
该方法返回与 sprite 发生碰撞的 group 中的 sprite 对象，dokill 为 bool(是否杀死group 中发生碰撞的 sprite)
4.pygame.sprite.groupcollide(组1,组2[,True,True]) # 组碰撞
第三个参数：是否 kill() 组1 中碰撞的精灵sprite
第四个参数：是否 kill() 组2 中碰撞的精灵sprite
返回值是一个字典的形式，键是 group 中碰撞的精灵 sprite
其中 group1 的碰撞精灵是它们的键，值是它们相交的 group2 精灵的列表
