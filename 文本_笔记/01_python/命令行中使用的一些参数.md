Python在终端中使用时的选项（参数）有很多，下面列举一些常用的：

- `-c <command>`: 在命令行执行Python代码。
- `-m <module>`: 以脚本的方式执行Python模块。
- `-i`: 执行完Python脚本后进入交互模式。
- `-h/--help`: 显示帮助信息。
- `-V/--version`: 显示Python版本号。
- `-O`: 生成优化的字节码，去除断言语句。
- `-OO`: 进一步优化字节码，去除文档字符串。
- `-B`: 关闭Python的缓存机制，可以避免.pyc文件的生成。
- `-E`: 禁用所有的环境变量，包括PYTHONPATH。
- `-c`: 以UTF-8编码执行Python脚本。
- `-q/--quiet`: 不输出任何Python警告信息。
- `-s`: 指定Python的路径，一般用于多版本的Python环境中。

# 安装pip

```bash
python -m ensurepip --default-pip
```

一个 Python 命令行选项，用于确保安装了 pip 包管理器，并使用默认的 pip 版本。当在一个新的 Python 环境中第一次安装 pip 时，使用该选项可以确保安装了默认的 pip 版本。如果已经安装了 pip，则此选项将不会产生任何影响。

该命令的具体含义如下：

- `python`：用于在命令行中运行 Python 解释器。
- `-m`：用于运行指定的模块作为脚本。
- `ensurepip`：Python 内置的一个模块，用于安装和管理第三方包管理器 pip。
- `--default-pip`：使用默认的 pip 版本进行安装。

运行该命令会自动安装默认版本的 pip 包管理器。
