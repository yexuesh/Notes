    """

    whence：可选参数，用于指定文件指针要放置的位置. 
            该参数的参数值有 3 个选择：
                0 文件头（默认值）
                1 当前位置
                2 文件尾
    `       例如，当whence == 0 && offset == 3（即 seek(3,0) ），表示文件指针移动至距离文件开头处 3 个字符的位置；当whence == 1 && offset == 5（即 seek(5,1) ），表示文件指针向后移动，移动至距离当前位置 5 个字符处。
