# os.mkdir(path,mode=00777,*,dir_fd=None)
os.mkdir(path) 创建一个文件,如果已存在抛出 FileExistsError 异常

os.path.isfile(path) 如果 path 是 现有的 常规文件，则返回 True
os.path.isdir(path)  如果 path 是 现有的 目录，则返回 True
os.path.exists(path) 如果 path 指向一个已存在的路径或已打开的文件描述符，返回 True(在某些平台上，如果使用 os.stat() 查询到目标文件没有执行权限，即使 path 确实存在，本函数也可能返回 False)

os.path.abspath(path)  # 获取文件所在的绝对路径
os.path.dirname(p)  # p为绝对路径, 获取文件所在目录

os.path.split(path) -> ("D:\\1\\2", "3")

# 常用命令

```python
创建目录（文件夹）：os.mkdir()

创建目录：os.mkdir(directory_name)
列出目录中的文件和子目录：os.listdir()

列出目录内容：os.listdir(directory_path)
删除目录（文件夹）：os.rmdir()

删除目录：os.rmdir(directory_name)
重命名文件或目录：os.rename()

重命名文件或目录：os.rename(old_name, new_name)
删除文件：os.remove()

删除文件：os.remove(file_name)
判断文件或目录是否存在：os.path.exists()

判断文件或目录是否存在：os.path.exists(file_or_directory_path)
判断路径是否是目录：os.path.isdir()

判断路径是否是目录：os.path.isdir(directory_path)
判断路径是否是文件：os.path.isfile()

判断路径是否是文件：os.path.isfile(file_path)
获取文件大小：os.path.getsize()

获取文件大小：os.path.getsize(file_path)
获取文件的绝对路径：os.path.abspath()

获取文件的绝对路径：os.path.abspath(file_path)
```
