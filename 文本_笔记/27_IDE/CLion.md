## 快捷键

按Ctrl-Shift-Enter将语句完成为语法正确的构造。
如if、do-while、try-catch、switch-case或return。

按Ctrl + P键以显示有效参数列表。

Alt + Inter 快速生成构造/析构/getter/setter....等函数

Ctrl + E 历史打开文件

Ctrl + F12  整体结构预览

Ctrl + F6 快速修改函数参数

Ctrl + Shift + I 提供变量/函数的简单浏览

Alt + Shift + 1 快速修改右侧视图

Ctrl + Alt + V 快速将一个表达赋给一个变量

Ctrl + shift + F7 高亮显示

Ctrl + O 快速覆盖基类的函数。 要实现纯虚函数，请使用 Ctrl I （代码 | 实现方法）。

Alt + Enter 正则表达式检测

 Ctrl   Alt   Shift   Insert 临时文件编写
