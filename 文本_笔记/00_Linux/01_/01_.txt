命令    
       一：    
            命令                                                             对应英文                                                                                               作用 
          1.  ls(list)  查看当前文件夹下的内容
          2.  pwd(print wrok directory)  查看当前所在文件夹
          3.  cd [目录名](change directory) 切换文件夹
          4.  touch [文件名](touch)    如果文件不存在，新建文件，修改文件的末次修改日期
          5.  mkdir [目录名](make directory)   创建目录
          6.  rm [文件名](remove)  删除指定的文件（名）
          7.  clear   清屏
          8.  tree [目录名]  以树状图列出文件目录结构
          9.  cp [源文件] [目标文件](copy)   复制文件或者目录
          10. mv [源文件] [目标文件](move)   移动文件或目录/文件或目录重命名
          11. cat [文件名](concateate)     查看文件内容、创建文件、文件合并、追加文件内容等
          12. more [文件名]   分屏显示文件内容
          12. less [文件名] 
          13. grep [搜索文本/文件名]  搜索文本内容
          14. echo 会在终端中显示参数指定的文字，通常会和 重定向 联合会使用
          14.0 head [:文件名:] 显示文件前十行内容
               head -n [:数字:] 显示前n行 
          14.1 tail [:文件名:] 显示文件尾十行内容
               (同head)
               tail -f [:文件名:] 实时更新文件内容
          15. > 和 >>    将本应显示在终端上的内容 输出/追加 到谁指定文件中
                >    表示输出，会覆盖文件原有内容
                >>  表示追加，会将内容最佳导演已有文件的末尾
                如： echo  hell python  >  a
          16. |  管道  左边写入，右边读取  (常用的管道命令: more: 分屏显示内容; grep: 在命令执行结果的基础上  
          	       查询指定文本) 如： ls  -lh  |  more
          17. shutdown  关机/重启;
              shutdown -h now 立即关机
              shutdown 5 "发送消息" 5分钟之后关机
              shutdown -r 重新启动(默认为一分钟后);
              shutdown -r now 立刻重启;
              shutdown -c 取消;
              shutdown  00:00/+10;
              halt 关机;
              reboot 重启;
              sync 把内存数据同步到磁盘;
          18. ifconfig  查看或配置网卡信息
          19. ping  【IP地址】  检测到目标  IP地址  的连接是否正常
          20. ssh/scp  远程登录和复制文件
              1>  ssh  [-p port]  user@remote              
                     scp  -P  port  01.py  user@remote:Desktop/01.py(把 01.py  复制到  远程家目录下
                     De....../01.py）（前面是要复制的，后面是复制到...）
                     scp  -P  port  user@remote:Desktop/01.py  01.py(把 远程家目录下De....../01.py  复
                     制到，目录01.py)
                     scp  -P  port  -r  ...  可以将传输目录而不只是文件
          
                    user 实在远程机器上的用户名，如果不指定默认为当前用户
                    remote  是远程机器的地址，可以是  IP/域名  ，或者是  别名
                    port  是  SSH Server  监听的端口，如果不指定，默认为22  
              2>  ssh-keygen  生成免密码登录的加密文件  id_rsa（私钥）  id_rsa.pub（公钥）
                     ssh-copy-id  user@remote  (会复制到  **（该用户的家目录）/.sshauthorized_keys  (该
                     文件与  id_rsa.pub内的内容相同)) 
                  （非对称加密算法：使用  公钥  加密的数据，用  私钥  解密，使用  私钥  加密的数据用  公钥  
                  解密）
              3>  配置别名：
                         ~/.ssh/config  >>  
                         Host  mac(别名)
                             HostName  170.148.114.1(ip地址）
                             User  itheima(远程计算机的用户名）
                             Port  22 
          21. exit  退出
          22. man [:命令或配置文件:]或help [:命令:]帮助
          23. ln -s [:原文件或目录名:] [:软链接名:]
          24. history [:'数字':] 历史
              history ![:'数字':] 执行历史指令N
          25. data 显示当前时间
              data +%Y
              data +%m
              data +%d
              data "+%Y-%m-%d %H:%M:%S"
              data +%Y
              data -s "+%Y-%m-%d %H:%M:%S" 设置时间
          26. cal 显示日历

       三  ：
            1.  ls
                0>  通配符  
                    *   代表任意多个字符   （如 ：ls  1*、ls  *1.txt、ls *3*)
                    ?   代表任意一个字符      (如 ：ls  1?1、ls ?2?.txt)
                    []  表示可以匹配字符组中的任意一个     (如: ls [12345]23.txt)
                    [abc]  匹配a、b、c中的任意一个
                    [a-f]  匹配 a 到 f 范围内的任意一个字符
                1>  ls  -a  查看所有文件
                2>  ls  -l  以列表方式显示文件的详细信息
                3>  ls  -h  配合  -i  以人性化的方式显示文件大小
                4>
             2.  cd
                 1>  cd或cd  ~   切换到当前用户的主目录（home/用户）
                 2>  cd  .       保持当前目录不变
                 3>  cd  ..      切换到上级目录
                 4>  cd  -       交换
             3. mkdir 
                 1>  mkdir  -p   可以递归创建目录     （如：mkdir  -p  a1/b1/c1)
             4. rm 
                 1> rm  -f  强制删除，忽略不存在的文件，无需提示
                 2> rm  -r  删除目录(不加  -r  只能删除文件 )/递归地删除目录下的内容， 删除文件夹 时必须加
                 此参数
             5. tree 
                 1> tree  -d  只显示目录
             6. cp
                 1> cp  -f  已经存在的目标文件直接覆盖，不会提示
                 2> cp  -i  覆盖文件前提示
                 3> cp  -r  若给出的源文件是目录文件则cp将递归复制该目录下的所有子目录和文件，目标文件必
                 须为一个目录名
             7. mv
                 1> mv  -i  覆盖文件前提示
             8. cat 
                0> 回一次显示所有内容，适合内容少的
                1> cat  -b  对非空输出行编号
                2> cat  -n  对输出的所有行编号
             9. more
                0> 分屏显示文件内容，每次只显示一页内容，适用于查看内容较多的文本文件
                1> 空格键/f          显示手册下一屏
                      Enter             一次滚动手册页的一行
                         b                  回滚一屏
                （空格键f          前滚一屏）
                         q                  退出
                     /word            搜索  word  字符串
             10. gerp
                 0> grep a 123.txt或grep "hell python" 123.txt
                 1> grep -n  显示匹配行及行号
                 2> grep -v  显示不包含匹配文本的所有行
                 3> grep -i   忽略大小写
                 4> ^a     行首，搜索以 a 开头的行
                 5> ke$  行尾，搜索以 ke 结束的行
